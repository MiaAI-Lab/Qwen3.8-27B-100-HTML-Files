TITLE: Portrait No. 7 - Generative Line Study
PROMPT: LINE PORTRAIT - generative face, 'PORTRAIT NO. 7'. SVG built as string: ~80 single-weight strokes on #f4efe4 forming a stylized abstract face - jaw arc, cheek lines, eye (two arcs + lash ticks), brow, lips (two curves), hair (12 flowing strokes), all #1c1a17. On load each stroke draws itself via stroke-dashoffset, staggered over 12s (the face is being sketched). Controls: VARIATION (new seed: control points jitter +/-12%, re-draw), INK chips (sumi black / sepia #7a5a3a / indigo #2f3f8f), GRID toggle (faint construction circles - art-school style). Thin double frame + caption 'LINE STUDY 07 - 80 STROKES'.
DESCRIPTION: A generative line drawing presented as an art-school sheet: warm paper (#f4efe4) inside a thin double frame, where about eighty single-weight strokes assemble a stylized abstract face - jaw arc, neck, brows, twin eyes with lid and lash ticks, nose alae, a two-curve mouth, twelve flowing hair strokes, and cheek lines. Every control point is jittered ±12% from a seeded PRNG, so each VARIATION redraw is a fresh portrait. On load the strokes sketch themselves in via stroke-dashoffset, staggered across roughly twelve seconds. An art-school GRID toggle reveals faint construction circles and centerlines beneath the ink, and three INK chips recolor the whole sheet (sumi black, sepia, indigo) with a smooth transition.
TECHNIQUES: svg-as-string construction, seeded mulberry32 PRNG, control-point jitter (±12%), stroke-dashoffset staggered draw-in via CSS transitions, CSS custom-property ink recolor, dashed construction grid layer, double-frame paper sheet aesthetic
INTERACTION: VARIATION button reseeds and re-sketches the portrait; three INK chip buttons switch stroke color (sumi / sepia / indigo); GRID button toggles faint construction circles; no keyboard or pointer-drawing - discrete button/chip controls only
