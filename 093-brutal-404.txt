TITLE: Brutal 404
PROMPT: BRUTAL 404 - bg #f2f0ec, ink #0d0d0d, accent #d63a3a. Massive '404' (~30vw, system-ui 900, tight) with a hard 12px red offset shadow. Below: 'ERROR: THE PAGE YOU SEEK HAS LEFT THE BUILDING' mono caps. A single-line SVG rectilinear maze (20x12) that continuously auto-draws its solution path in red (dash animation loop). Buttons GO BACK / HOME / SOS: flat, 2px black border; hover inverts + 4px offset shadow. SOS: whole page shakes 300ms + 'STILL LOST?' appears. Top marquee strip scrolls '404 - NOT FOUND - 404 -'. Footer: 'BUILT BY NO ONE. HOSTED BY SOMEWHERE.' No gradients, no radius, all flat and loud.
DESCRIPTION: A loud, flat, zero-corner 404 page. Paper-white background with ink-black type and one red accent. A 30vw-weight-900 '404' sits slightly rotated with a hard 12px red offset shadow; below it, a mono-caps error line boxed by black rules calls out that the page 'HAS LEFT THE BUILDING'. The centerpiece is a 20x12 single-line SVG rectilinear maze generated at load (seeded backtracker, fully deterministic) with a red solution path that continuously draws and erases itself via a stroke-dashoffset loop, flanked by a red start dot and black exit square. GO BACK / HOME / SOS buttons are flat with 2px black borders that invert and gain a 4px offset shadow on hover. SOS makes the whole stage shake for 300ms and flashes 'STILL LOST?' in blinking red caps. A sticky black marquee strip scrolls '404 - NOT FOUND -' endlessly, and a black footer reads 'BUILT BY NO ONE. HOSTED BY SOMEWHERE.' Everything is flat, sharp, and uneven on purpose - no gradients, no border-radius.
TECHNIQUES: flat brutalist color blocking, hard offset text-shadow type, system-ui 900 display scale with clamp(), sticky CSS marquee with translateX loop, seeded deterministic RNG (mulberry32), recursive-backtracker perfect maze generation, BFS shortest-path solve, single-path runtime SVG built via innerHTML string, stroke-dasharray/pathLength=1 solve/erase keyframe loop, step-timing blink, JS-forced-reflow shake retrigger, hover invert + offset-box-shadow micro-interaction, square caps only
INTERACTION: three flat buttons (GO BACK triggers history.back, HOME scrolls to top, SOS shakes the page 300ms and flashes 'STILL LOST?' for ~2.4s); hover states invert button fill and add a 4px red offset shadow; sticky marquee and maze solve loop run continuously; no keyboard handling; pointer hover on buttons only.
