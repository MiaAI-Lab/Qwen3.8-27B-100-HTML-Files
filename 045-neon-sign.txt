TITLE: Neon Sign Factory
PROMPT: NEON SIGN FACTORY - dark shop wall #14100e with subtle brick texture (repeating gradients); a neon sign of user text (default 'OPEN') drawn on canvas: each character stroked in a huge system font, two passes - wide glow (#ff2e88, alpha .25, shadowBlur 24) then core (#ffd9ef, no blur); FLICKER mode dims one random letter every ~1.4s (classic broken neon). Controls: text input (max 12 chars), color chips (pink #ff2e88, cyan #27e0ff, green #46ff9e, amber #ffb454), STYLE chips (SCRIPT/MONO/BLOCK font stacks), flicker toggle, HUM sound (WebAudio 120Hz buzz + crackles, gesture-created). Caption 'CUSTOM NEON - EST. 1987'.
DESCRIPTION: A dark brick shop wall built entirely from repeating-linear-gradient layers in CSS, framed by a mounted sign box with inset shadows and a vignette. Inside, a canvas draws the user's text (default OPEN, max 12 uppercase chars) character by character at a huge adaptive size with a two-pass neon technique: first a wide glow pass (theme color at alpha .25 with shadowBlur 24), then a crisp pale core pass with no blur, plus a tiny micro-jitter so the light never sits perfectly still. FLICKER mode picks a random letter and dims it to a broken-neon glow roughly every 1.4 seconds (0.4-2.6s random cycle), and each re-break fires an audio crackle when HUM is on. The control panel offers a mono-styled text field, four round color swatches (pink/cyan/green/amber) that also recolor the HUM button, SCRIPT/MONO/BLOCK style chips that swap the system font stacks, and a HUM toggle that lazily creates a WebAudio graph on first gesture: a 120Hz sawtooth plus 60Hz sine through a low-pass with an 8Hz tremolo LFO, plus band-passed square crackle blips on flicker events.
TECHNIQUES: CSS brick texture via offset repeating-linear-gradient layers and vignette overlay, two-pass canvas glow (shadowBlur halo + core), per-character adaptive font sizing, broken-letter flicker state machine with eased dim, micro jitter on alpha, DPR-aware resize with fit() on boot, lazy-gesture WebAudio hum (sawtooth+sub through lowpass with tremolo LFO) and bandpass crackle blips
INTERACTION: text input (max 12 chars, auto-uppercased) redraws the sign live; four color swatch buttons set the neon color; SCRIPT/MONO/BLOCK style chips swap the font stack; FLICKER toggle enables broken-letter dimming; HUM toggle creates the WebAudio context on first click and starts/stops the buzz with crackle accents on each flicker re-break
